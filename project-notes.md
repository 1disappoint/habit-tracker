# Project Notes

- Тема: трекер привычек
- Цель: отслеживание ежедневных привычек
- Планируемые функции: создание привычки, отметка выполнения, статистика

## Примеры использования
- Пользователь добавляет привычку «Пить воду».
- Каждый день отмечает выполнение.
- В конце недели видит, сколько дней подряд выполнено.

## Статистика
- Количество выполненных дней
- Текущая серия (streak)
- Процент выполнения за период
